# اختصارات المحرر الحالية

تعكس هذه القائمة bindings الموجودة في `EditorShell` ومعالجة المفاتيح في المحرر. وجود binding لا يعني وحده أن كل مساراته لها widget regression؛ راجع [استراتيجية الاختبار](../testing/test-strategy.md) ونتائج الاختبارات الفعلية قبل وصف السلوك بأنه مثبت بالكامل.

## الاختصارات المربوطة

| الفئة | الاختصار | السلوك في التطبيق |
|---|---|---|
| ملف | Ctrl/Cmd+S | حفظ الوثيقة الحالية |
| ملف | Ctrl/Cmd+Shift+S | حفظ باسم |
| ملف | Ctrl/Cmd+N | إنشاء ملف من المحرر |
| ملف | Ctrl/Cmd+O | فتح ملف |
| ملف | Ctrl/Cmd+W | إغلاق التبويب النشط؛ يطلب تأكيدًا عند وجود تغييرات غير محفوظة |
| تحرير | Ctrl/Cmd+Z، Ctrl/Cmd+Y | تراجع وإعادة |
| تحرير | Ctrl/Cmd+Shift+K | حذف السطر الحالي |
| تحرير | Ctrl/Cmd+Enter، Ctrl/Cmd+Shift+Enter | إدراج سطر أسفل/أعلى |
| تحرير | Alt+Up/Down | نقل السطر |
| تحرير | Shift+Alt+Up/Down | نسخ السطر |
| تحرير | Ctrl/Cmd+D | تحديد التكرار التالي |
| تحرير | Ctrl/Cmd+Shift+D | تكرار السطر |
| تحرير | Ctrl/Cmd+L | تحديد السطر الحالي |
| تحرير | Ctrl/Cmd+/ | تبديل تعليق الأسطر باستخدام `//` |
| تحرير | Cmd+Option+F على macOS؛ Alt+Shift+F أو Ctrl+Shift+I على Windows/Linux | تنسيق الوثيقة |
| تنقل | Ctrl/Cmd+PageUp/PageDown | اختيار التبويب السابق/التالي |
| تشخيص | F8، Shift+F8 | الانتقال إلى التشخيص التالي/السابق |
| بحث | Ctrl/Cmd+F | فتح/تبديل شريط البحث والاستبدال |
| عرض | Ctrl/Cmd+J | إظهار/إخفاء لوحة النتائج |
| عرض | Ctrl/Cmd+=، Ctrl/Cmd+-، Ctrl/Cmd+0 | تكبير النص وتصغيره وإعادة المقياس |
| Compiler | F5 | بناء artifact للملف النشط ثم تشغيله |
| Compiler | Ctrl/Cmd+F5 | بناء artifact native |
| مساعدة | F1 | طلب المساعدة |
| مساعدة | Ctrl/Cmd+Space | طلب completion |

داخل محرر النص: `Tab` يقبل completion عند وجوده، وإلا يدخل indentation؛ `Shift+Tab` ينقص indentation؛ السهمان الرأسيان يبدلان completion عند ظهورها؛ و`Escape` يغلق completion أو المساعدة. الأسهم الأفقية تعالج الحركة البصرية في RTL، وEnter يدرج سطرًا مع indentation.

## سلوك غير مربوط حاليًا

لا يوجد binding معلن لـCtrl/Cmd+H أو Ctrl/Cmd+B أو Ctrl/Cmd+1..9. إغلاق التبويب لا ينبغي وصفه بأنه يطلب تأكيد dirty state ما لم يثبت التنفيذ الحالي ذلك. كما لا توجد أوامر F2 لإعادة تسمية رمز أو F12 للانتقال إلى تعريف دلالي؛ إعادة تسمية ملف explorer عملية مختلفة عن إعادة تسمية رمز في اللغة.

تُنفذ عمليات explorer مثل إنشاء ملف/مجلد، فتح مجلد، تحديث الشجرة، قص/لصق وإعادة تسمية/حذف الملف من أزرار وقوائم السياق، لا من الاختصارات المذكورة أعلاه.

## معيار الإثبات

تصف هذه الوثيقة bindings الحالية في المصدر. لا تسجل الميزة على أنها regression-tested إلا إذا كان لها اختبار يغطي الاستدعاء والنتيجة. اختبارات keyboard shortcuts المرئية موجودة في `test/widget_test.dart` لبعض السلوكيات، ومنها Ctrl/Cmd+/، ويستمر اختبار بقية الأوامر ضمن الاختبارات الخاصة بالمحرر عند إضافتها.
