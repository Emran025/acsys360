# نتائج دراسة تلوين VS Code

## الخلاصة التنفيذية

تتكون عملية التلوين في VS Code من مرحلتين متكاملتين: **تقسيم النص إلى tokens وتصنيفها**، ثم **ربط التصنيفات بألوان وأنماط من خلال الثيم**. التلوين المعجمي هو الطبقة الفورية التي تعمل أثناء الكتابة، بينما يضيف التلوين الدلالي معلومات أعمق من خدمة اللغة عندما تتوفر معرفة الرموز والسياق.[1] [2]

## ما يطبّق في Arabic360

يستخدم Arabic360 tokens التي ينتجها lexer في `packages/compiler_c/src/lexer.l` مصدرًا للتصنيف المعجمي، ثم يحولها highlighter إلى spans لونية. لا تعتمد الواجهة على Regex مستقل يعيد تعريف قواعد اللغة، لأن ذلك قد يجعل النص الملون مختلفًا عن النص الذي يقبله المترجم.

تضيف الواجهة semantic refinement خفيفًا من compilation result لأدوار الثابت والنوع والإجراء والمعامل والمتغير. يعتمد هذا الربط على أسماء الرموز ولا يحل shadowing ولا يعادل semantic tokens لخدمة لغة كاملة. عند وجود diagnostics تبقى الطبقة المعجمية، وتعلو زخرفة التشخيص على لون token.

## قواعد الجودة

| القاعدة | التطبيق |
|---|---|
| فورية التحديث | يعاد تلوين النص بعد التعديل دون تغيير `TextEditingValue` أو selection |
| مصدر واحد للحقيقة | Lexer/TokenKind هو مصدر التصنيف الأولي، ولا يُعاد اختراع grammar في Widget |
| فصل المسؤوليات | highlighter يحول tokens إلى spans، والثيم يحدد الألوان، والمحرر يعرضها فقط |
| تحمل الأخطاء | النص غير المكتمل يظل قابلًا للتلوين الجزئي ولا يوقف الكتابة |
| التدرج | lexical highlighting فوري، وsemantic refinement بعد نجاح التحليل |
| RTL آمن | اتجاه النص ومسافات المؤشر لا تتغير بسبب ترتيب رسم الألوان |

## إعدادات التحرير التي يجب محاكاتها

يوفر إعداد اللغة في VS Code قواعد مستقلة للتعليق السطري والكتلي، تعريف الأقواس، الإغلاق التلقائي، إحاطة النص المحدد، الطي، نمط الكلمة، وقواعد الإزاحة. كما يميز بين زيادة الإزاحة وخفضها وقاعدة السطر التالي.[3]

تدعم grammar الحالية التعليق الخطي `//`، ويستخدمه أمر Ctrl/Cmd+/؛ التعليق الكتلي `/* */` ليس ضمن الصياغة الحالية ولا ينبغي إضافته للمحرر. يعالج `ToggleLineComment` التعديل كعملية واحدة قابلة للتراجع ويحافظ على تحديد الأسطر وفق use case الخاص به.

يدخل Enter سطرًا جديدًا مع الإزاحة السابقة، ويضيف مستويين من المسافات إذا انتهى النص قبل المؤشر بـ`{`. لا ينفذ المحرر formatter كاملًا مع كل حرف؛ التنسيق أمر صريح لتجنب إعادة بناء المصدر أو فقد selection.

[3]: https://code.visualstudio.com/api/language-extensions/language-configuration-guide "VS Code Language Configuration Guide"
