# 01 — المتطلبات ومخرجات التكليف

## 1. الهدف

يهدف المشروع إلى بناء لغة برمجة عربية ذات قواعد محددة، ومترجم أكاديمي يمر بمراحل التحليل المعجمي والنحوي والدلالي ثم يولد تمثيلات وسيطة ومخرج Assembly نصيًا وartifact تنفيذيًا عند تحقق شروط backend. ويرتبط المترجم بمحرر Flutter Desktop مستقل يتيح إنشاء Workspace واختيار مجلد وإدارة ملفات `.arb` وكتابة البرامج وتشغيل التحليل والتنفيذ.

## 2. المخرجات الأكاديمية

| المخرج | معيار القبول |
|---|---|
| Tokens | قائمة فعلية من Lexer، مع نوع token وlexeme وموضع المصدر |
| Parse/Syntax Tree | شجرة AST مشتقة من parser، لا تمثيل نصي يدوي |
| Symbol Table | رموز الأنواع والمتغيرات والثوابت والإجراءات والمعاملات مع النوع والملكية والموقع عند توفره |
| Lexical Errors | تشخيص للرموز غير المعروفة والنصوص أو المحارف غير المغلقة |
| Syntax Errors | تشخيص موضعي للإنتاج غير المطابق مع استمرار parsing الآمن عند الإمكان |
| Semantic Errors | فحص التعريف والتوافق النوعي والوصول والاستدعاءات وlvalue والشروط |
| Three-Address Code | تعليمات وسيطة ناتجة من AST والتعبيرات والتحكم والاستدعاءات |
| Assembly | مخرج نصي NASM-like قابل للفحص الأكاديمي، مع التصريح بأنه غير assembled ما لم ينفذ assembler حقيقي |
| Execution | تنفيذ داخلي للبرنامج الصحيح مع `executionOutput` منفصل عن artifact |
| Native Artifact | executable حقيقي يعاد مساره فقط بعد نجاح `dart compile exe` والتحقق من الملف |
| Examples | عشرة أمثلة عربية متنوعة تغطي الحساب والتعريفات والشرط والحلقات والإجراءات والمراجع والقوائم والسجلات والبرنامج المركب |
| Editor | محرر مستقل يتصل بالمترجم التنفيذي عبر JSON protocol versioned |

## 3. حدود النطاق

لا تضيف اللغة صياغة تشبه C أو Java لمجرد تسهيل التنفيذ. الكلمات والرموز والتراكيب المقبولة هي التي تحددها وثيقة القواعد العربية. ويُرفض أي امتداد جديد ما لم يضاف إلى lexer وparser وAST وsemantic وruntime وbackend والاختبارات والتوثيق معًا.

لا يُعد interpreter بديلًا عن compiler backend، ولا تُعد Assembly النصية ملفًا تنفيذيًا، ولا يُفترض أن يعمل native build من نسخة المستخدم إلا إذا كانت حزمة release تحتوي toolchain اللازمة أو كان backend مستقلًا عنها. في الإصدار self-contained الحالي تُرفق Dart SDK داخل `compiler/dart-sdk` في حزم Desktop.

## 4. حالات الاستخدام الأساسية

يبدأ المستخدم دون Workspace افتراضي ظاهر، ثم يختار مجلدًا من خلال dialog. بعد ذلك يستطيع إنشاء ملف عربي أو فتح ملف قائم وتحريره، والتنقل في شجرة المشروع، والحفظ، والتحليل، وعرض نتائج المراحل، وبناء artifact من الملف النشط عبر Ctrl/Cmd+F5. لا تتسرب ملفات Workspace إلى المحرر عند عدم اختيار مجلد.

أثناء الكتابة يجب أن يبقى النص الحقيقي مستقلًا عن النص الشبح للاقتراح. قبول الاقتراح يتم عبر Tab فقط، بينما كتابة حرف مختلف تغلق الاقتراح وتُدخل الحرف مرة واحدة. Escape يغلق الاقتراح دون تعديل، والأسهم وHome وEnd تحرك المؤشر داخل النص ولا تختار اقتراحًا أو تعيد تعيين القيمة.
