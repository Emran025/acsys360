# 04 — مواصفة سلوك المحرر

## 1. مبدأ الإدخال

يمتلك المحرر مصدرًا واحدًا للحقيقة هو `TextEditingController.value`. النص الشبح للـ completion عرض بصري فقط، ولا يضاف إلى `controller.text`. ولا يجوز لأي listener أن يعيد تعيين `TextEditingValue` أثناء دورة onChanged إلا عند مزامنة تغيير خارجي موثق.

## 2. دورة الاقتراح

| الحدث | النتيجة |
|---|---|
| كتابة حرف عادي مع وجود ghost text | يمر الحرف إلى TextField مرة واحدة، ثم يُغلق الاقتراح من خلال onChanged؛ لا يُستهلك الحرف كأمر رفض |
| Escape | إغلاق الاقتراح فقط دون تغيير المصدر |
| Tab مع اقتراح | قبول العنصر الحالي وتحديد المؤشر بعد النص المدخل |
| Tab بلا اقتراح | إدخال indentation وفق إعداد اللغة |
| السهمان الأعلى والأسفل مع القائمة | تغيير عنصر الاقتراح فقط عندما يكون ذلك مقصودًا، وإلا تبقى حركة المؤشر طبيعية |
| السهمان الأيسر والأيمن | تحريك selection داخل النص، ولا يعادلان قبولًا أو رفضًا صامتًا |
| Home/End | الانتقال إلى بداية أو نهاية السطر داخل محرر الكود، لا إلى نهاية البرنامج |
| نتيجة طلب قديم | تُهمل إذا تغير رقم generation منذ إرسال الطلب |

## 3. الاتجاه والمؤشر

واجهة التطبيق وشجرة المشروع عربية RTL. مساحة تحرير الكود تستخدم `TextDirection.rtl` و`TextAlign.right` حتى يتحرك caret مع الإدخال العربي ولا يبقى مثبتًا عند الحافة اليمنى. يحتفظ المحرر بالترتيب المنطقي للنص المختلط من خلال selection offsets، بينما يعرض `gutter` أرقام الأسطر إلى يمين مساحة الكود، وتبقى Minimap إلى يسارها. لا يُستخدم RTL للواجهة بدلًا من معالجة selection؛ بل يُختبر الاثنان مع العربية والأرقام والرموز.

عند تبديل الملف أو مزامنة تغيير خارجي، يحافظ المحرر على selection ضمن طول النص بدل وضعه تلقائيًا في النهاية. وعند الإدخال المحلي يظل offset الناتج هو `start + insertedLength`، ويُمنع أي listener لاحق من استبداله بالمؤشر الافتراضي.

## 4. Enter وindentation

يحسب Enter بداية السطر الحالي، ويحتفظ بالمسافات أو tabs البادئة. إذا انتهى محتوى السطر قبل المؤشر بعلامة `{` يضاف مستوى indentation جديد بمقدار مسافتين. يدخل السطر الجديد مرة واحدة وتوضع selection بعد indentation الجديدة. لا يعمل formatter الكامل مع كل حرف؛ لأن ذلك يعيد بناء النص ويهدد موضع المؤشر.

## 5. التنسيق والتلوين

التلوين يستهلك token matches من النص دون تغيير النص أو selection. تصنف الألوان التعليقات والخيوط والمحارف والأرقام والمنطقيات والأنواع والكلمات المحجوزة والعوامل والرموز والمعرفات إلى ألوان مستقلة. أما formatter فيعمل صراحة عبر الاختصار أو الأمر المخصص ويعيد تعديلًا قابلًا للتراجع.

## 6. الملفات والأيقونة

يظهر شعار Arabic360 المسجل في `assets/branding/arabic360.png` على ملفات `.arb` داخل شجرة Workspace، بينما تستخدم الملفات الأخرى أيقونات نوعية. لا يعتمد العرض على مسار التطبيق الافتراضي، ولا يظهر Workspace قبل أن يختار المستخدم مجلدًا.

## 7. الاختصارات الأساسية

يحافظ المحرر على اختصارات الحفظ والتراجع والإعادة والبحث وإغلاق التبويب والتنقل بين التبويبات وتحليل الملف وبناء artifact، إضافة إلى حذف السطر وتكراره ونقله ونسخه وتحديده. يجب ألا تتعارض اختصارات الاقتراح مع مفاتيح الإدخال الأساسية أو تمنع TextField من معالجة الحرف.
