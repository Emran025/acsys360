# 09 — بوابة الجودة الإنتاجية والأكاديمية

## الغرض

تحدد هذه الوثيقة معيار القبول الذي يجب أن يمر به كل مكوّن في Arabic360. لا يكفي أن يظهر المكوّن في الواجهة أو أن يمر البناء الشكلي؛ يجب أن يكون سلوكه محددًا، قابلًا للاختبار، موثقًا، ومتسقًا مع حدود اللغة العربية المطلوبة في التكليف.

## طبقات القبول

| الطبقة | معيار القبول | الدليل المطلوب |
|---|---|---|
| صحة اللغة | Lexer وParser وSemantic Analyzer يرفضون النص غير الصحيح برسائل واضحة، ويقبلون الصيغ التي تنتمي إلى grammar المعتمدة فقط | اختبارات grammar وdiagnostics ومصادر أمثلة عربية |
| المخرجات الأكاديمية | تظهر Tokens وAST/Syntax Tree وSymbol Table والأخطاء الدلالية و3AC وTyped IR وAssembly النصية ونتيجة التنفيذ في مراحل مستقلة | اختبارات protocol ولقطات نتائج أو مخرجات قابلة للحفظ |
| التنفيذ | لا يُعاد مسار artifact إلا بعد إنشاء ملف تنفيذي حقيقي والتحقق من وجوده وفق target المعلن | protocol smoke test وسجل CI ومسار artifact |
| المحرر | لا يستهلك رفض الاقتراح الحرف، ولا يغيّر selection خارجيًا، ولا يقفز إلى EOF، ويحافظ Enter على indentation وحركة الأسهم | Flutter widget tests وتحقق CI |
| التنقل | Minimap وgutter وscroll والمؤشر تستخدم مصدر حقيقة واحدًا ولا تنشئ محررًا موازيًا | اختبار النقر والسحب وتزامن scroll |
| التوثيق | كل متطلب له ملف Markdown أو اختبار أو مخرج محدد، مع فصل ما نُفذ عن المخطط والحدود | `docs/assignment/06-deliverables-checklist.md` وتلك الوثيقة |
| الإصدار | ينجح format وanalyze وtest وdesktop build، وتُبنى أصول Windows/Linux/macOS من tag غير قابل لإعادة الكتابة | GitHub Actions وRelease assets |

## قاعدة عدم المبالغة

> لا يُعلن اكتمال ميزة لمجرد وجود نوع أو Widget باسمها. الإعلان يعتمد على اختبار يثبت السلوك ومسار بناء يثبت قابلية التشغيل، مع وصف صريح للميزات غير المدعومة.

## الأولويات التنفيذية

تُعالج الأخطاء التي تمس الكتابة أو سلامة المؤشر قبل التحسينات البصرية. ثم تُثبت المخرجات الأكاديمية في عقد typed JSON، وبعد ذلك تُحسن قابلية القراءة والتوثيق والإصدار. لا تُضاف أدوات مرئية زائدة إذا كان الاختصار أو النتيجة الحالية يؤدي الغرض بوضوح أكبر.

## معايير التسليم النهائي

يُعد الإصدار صالحًا للتسليم عندما يكون المستودع نظيفًا، ويمر CI بكامل وظائفه، وتكون أمثلة اللغة قابلة لإعادة الإنتاج، وتظهر نتائج المترجم في مراحل منفصلة، وتكون حدود `dart-native` موثقة، وتُرفق ملفات `docs/assignment/` مباشرة للتحويل إلى Word.
