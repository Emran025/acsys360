# ملاحظات تأسيسية محفوظة

> هذه قائمة اقتراحات تأسيسية تاريخية أُعدت قبل اكتمال البنية الحالية. ليست قائمة Issues مفتوحة ولا مصدرًا للحالة؛ راجع [خارطة الطريق الحالية](./roadmap.md) و[وثيقة المعمارية](../architecture/architecture.md).

البنود المتعلقة بإزالة Flutter starter، وإنشاء طبقات المحرر، وتعريف عقد JSON، وبناء compiler process adapter، وواجهة Workspace الأساسية تجاوزتها بنية المستودع الحالية. بقيت معاييرها هنا كسجل لمتطلبات التأسيس، ولا ينبغي استخدامها لإعادة إنشاء `apps/` أو `compiler_core` غير الموجودين.

## بنود تصلح كقوالب عمل لاحق

- توسيع Lexer وParser أو قواعد semantic فقط عند وجود fixture واختبار للبنية الجديدة.
- إضافة protocol action أو target جديد مع اختبار عقد وتكامل حقيقي.
- إضافة سلوك محرر أو explorer مع اختبار widget يثبت مسار المستخدم، لا اختبار repository وحده.
- تحديث workflow لكل منصة عند اعتمادها رسميًا، مع bundle smoke test.

قبل تحويل أي بند إلى GitHub Issue، تحقق من الحالة في الشيفرة والاختبارات الحالية لتجنب إعادة فتح عمل مكتمل أو إنشاء مسارات معمارية قديمة.
