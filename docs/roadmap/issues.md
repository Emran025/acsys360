# قائمة فرص العمل

هذه القائمة مقترحات غير مرتبطة تلقائيًا بـ GitHub Issues. راجع الحالة الحالية قبل إنشاء Issue، ولا تعتبر البنود دليلًا على غياب التنفيذ.

| ID | فرصة التحسين | الحالة/الدليل المتوقع |
|---|---|---|
| ED-EXPLORER-TESTS | إضافة widget tests لمستكشف Workspace | تغطية المحاذاة RTL وقوائم السياق وتدفقات الملفات |
| LANG-COVERAGE | توسيع مصفوفة grammar وbackend | fixtures إيجابية وسلبية لكل construct معلن |
| EDITOR-KEYS | استكمال اختبارات الاختصارات | regression tests لأوامر تحرير النص والتبويبات |
| LANGUAGE-SYMBOLS | إضافة مواقع دقيقة لرموز اللغة | protocol actions واختبارات navigation/rename حقيقية |
| ARTIFACT-TARGETS | توسيع تحقق targets التنفيذية | build/run smoke على كل منصة مدعومة |
| ACCESSIBILITY | فحص الوصولية للواجهة والشجرة | semantics، focus traversal، واختبارات وصولية |

راجع [خارطة الطريق](./roadmap.md) و[خطة التحسين](./improvement-plan.md) لتحديد الأولويات. تُنشأ Issue جديدة فقط بعد التأكد من عدم وجود تنفيذ أو عمل مفتوح يغطي نفس النطاق.
